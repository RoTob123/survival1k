# survival1k
**hello!**

this is the game where you fight enemies, level up and uhhh.. that's it?

**CONTROLS:**

- LUDR - move
- Z - drink water
- X - attack

**QUICK MANUAL:**

- you need to drink water or you'll start to lose hp
- there's 2 types of enemies - passive ( just wander around ), and aggressive ( chase you and damage )
- as you kill more and more enemies, you'll level up, dealing even more damage
- this game is in-dev right now, i plan to add more features if i can ( 1k is not a joke :| )

**TRIVIA:**

- i used shrinko8 to compress the game, originally it was ~1.2k. now its 1019 bytes *( PHEW... )*
- im going to make a github repo with deobfuscated rom so you could give ideas on how could i improve the game
